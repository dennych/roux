# 把魔方照片放进这个目录

## 拍三张（前两张顶层色朝上，第三张翻过来）

| 文件 | 角度 | 应该看到 |
|---|---|---|
| `photo-1.jpg` | 45° 俯视 | **上 / 前 / 右** |
| `photo-2.jpg` | 绕竖直轴转 180°（顶层色仍朝上） | **上 / 后 / 左** |
| `photo-3.jpg` | 上下翻转（原来的**前面仍朝前**） | **下 / 前 / 左** |

> 两张不够：任何 45° 视角都只看到"三对相对面里各一个"，同顶色的两张最多覆盖 5 个面，第 6 面只能靠约束推断。
> 拍三张就 6 面全覆盖，还能互相校验。

**手指千万别挡住魔方**（放桌面拍，或只捏最边缘）。也可以完全不用照片：直接在网页「手动填色」里点格子。

## 要求

- 格式：**JPEG 或 PNG**（手机默认的 HEIC 请先导出/截图成 JPEG）
- 光线均匀，**避免贴纸反光**和强阴影；魔方占画面 **1/3 以上**；对焦清楚；背景尽量干净
- 顺手告诉我：**顶层中心是什么颜色、正面中心是什么颜色**（例如"黄顶、红前"）

## 然后

放好照片跟我说一声（"照片放好了"）。我会：
1. 逐格读这 54 张贴纸 → 给你一串 54 个字母的状态串（如 `YYYYYYYYYBBB…`）
2. 你粘到网页「输入我的魔方」→「解析并载入」→ 和实物核对 → 点「下一步」逐步执行

> 也可以直接在对话里把照片拖进来，效果一样（更省事）。
